## Protected release contract

The release workflow:

- enforces the tag-to-package-version contract
- compiles and tests the source
- builds and validates the distributions
- installs the built wheel into an isolated runtime
- authenticates through GitHub OIDC and Workload Identity Federation
- runs a KMS-attested governed release demonstration
- publishes to TestPyPI through trusted publishing

## Published-package acceptance

The actual TestPyPI wheel was downloaded into a fresh environment and proved:

- installation from `site-packages`
- complete CLI availability
- unsigned governed execution fails closed
- local trust remains simulator-only
- poisoned cloud credentials are ignored
- IBM and KMS are not contacted during local verification
- all ten independent evidence-chain checks pass

## Alpha limitations

The public quickstart authorizes local Aer simulation only. Self-managed
hardware authority is not yet available. Interfaces and evidence schemas may
change before a stable release.
